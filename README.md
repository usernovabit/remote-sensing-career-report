# 生涯认知与目标初探报告（Remote Sensing Career Report）

遥感科学与技术专业（一年级）生涯认知与目标初探报告，聚焦 **GNSS / LiDAR** 方向。
本仓库用于版本管理与成果归档，也是 DSH GitHub MCP 接入后的默认工作仓库。

## 目录结构

```
├─ reports/
│  ├─ pdf/    最终交付 PDF（含封面署名与页码页脚）
│  └─ src/    报告源文件与生成脚本（DOCX / Python）
├─ documents/ 参考资料
└─ README.md
```

## 报告内容概要

| 章节 | 主要内容 |
|---|---|
| 一、开篇：专业初识与兴趣关联 | 从“操作精密仪器的专业”到“多学科交叉”的认知转变；课程收获（GNSS 与 IMU、SketchUp 制图）；印象最深的方向（三维信息、空间智能）与兴趣关联 |
| 二、职业方向初探 | 目标职业：无人机航测工程师、GNSS 数据处理工程师；核心工作、能力要求、专业课程匹配度 |
| 三、自我认知与初步规划 | 现有基础与四项差距；7 条短期可执行目标（Python 与 AI 工具 → C++ 与数学 → 文献阅读 → 大创课题） |
| 四、附件 | 个人兴趣与专业课程匹配度表；目标职业初步认知框架图（思维导图） |
